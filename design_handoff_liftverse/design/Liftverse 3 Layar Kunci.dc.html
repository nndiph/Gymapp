Catatan desain
Jangkauan ibu jari. Tombol Mulai ada di sekitar y 650 dp, di separuh bawah. Kartu latihan hari ini sengaja diletakkan di bawah ringkasan minggu.
Streak dari jadwal sendiri. Pengguna memilih split dengan hari tetap atau target per minggu (lihat lembar 4, Jadwal dan streak). Raka memakai hari tetap Senin sampai Kamis dari routine-nya, jadi Jumat sampai Minggu tidak memutus streak. Ketuk angka streak untuk mengubah jadwal.
Progress hari ini. Tiap gerakan di Latihan hari ini menunjukkan target, set sesi lalu, sparkline volume 6 sesi, dan perubahan vs bulan lalu. Pengguna tahu angka yang harus dikalahkan sebelum menekan Mulai.
Minggu ini vs minggu lalu. Batang berpasangan per hari dan perbandingan November vs periode yang sama di Oktober. Ketuk Progress untuk detail.
Lingkaran hari. Centang terisi = selesai, garis biru = hari ini terjadwal, putus-putus = terjadwal nanti, abu = istirahat. Bentuk dan label membedakan, bukan warna saja.
Data. Kamis 12 November sebelum latihan: 3 sesi minggu ini. Setelah Push Day selesai menjadi 4 sesi minggu ini, 8 sesi dan 41.200 kg bulan ini (state di Profil).
Tanpa jadwal. Jumat 13 November. Mulai sesi kosong jadi aksi utama, pilih routine kedua, dan jadwal berikutnya ditampilkan supaya pengguna tahu kapan harus kembali.

Catatan desain
Pencapaian langsung. Begitu angka di stepper melewati sesi lalu, chip kecil "↑ +2,5 kg" (volt) langsung muncul di judul set aktif. Bila estimasi 1RM melewati rekor, berubah menjadi "Calon PR" (kuningan). Tanpa panel teks tambahan supaya stepper tetap di posisinya. Tidak perlu menunggu set atau sesi selesai. Tercatat resmi saat Selesai set, lalu baris ringkas memakai tag ↑ +2,5 kg atau PR.
Baris set alternatif B. Set berikutnya otomatis mengembang dengan stepper besar. Set lain tampil ringkas. Detail di lembar 2.
1 ketukan. Angka abu adalah isian dari sesi lalu. Centang di baris ringkas atau Selesai set langsung menyimpan nilai itu.
Maksimal 3 ketukan. +/− lalu Selesai set = 2. Ubah beban dan reps = 3. Mengubah beban set aktif juga memperbarui set berikutnya yang nilainya sama.
Lompatan besar. Ketuk angka untuk numpad dengan tombol ±langkah. Langkah mengikuti gerakan: 2,5 kg barbell, 2 kg dumbbell.
Timer istirahat. Mulai otomatis saat set dicentang. Panel volt di atas tombol bawah: sisa waktu besar, −15/+15, Lewati, dan bilah progres linear. Ini momen volt paling kuat di aplikasi karena istirahat adalah bagian dari usaha.
Kalkulator plat. Untuk gerakan barbell, tombol Plat di panel set aktif membuka sheet susunan plat per sisi (bar 20/15/10 kg). Contoh: 82,5 kg = 25 + 5 + 1,25 per sisi.
Mengurangi. Tombol hapus di panel set aktif menghapus set itu. Ikon hapus di kepala gerakan menghapus gerakan dari sesi. Keduanya tanpa dialog, cukup snackbar Urungkan 5 detik, supaya tetap cepat di sela set.
Fokus. Hanya gerakan yang sedang berjalan yang terbuka; gerakan lain diringkas menjadi satu baris berisi set dan nilai sesi lalu.
Sinkron. Chip kecil di app bar: Tersimpan di perangkat sesaat setelah set dicentang, lalu Tersinkron. Tidak pernah memblokir layar.
Selesai memakai tonal biru supaya tidak bersaing dengan Selesai set, dan meminta konfirmasi bila masih ada set yang belum dicentang.

Catatan desain
Heatmap satu baris, 6 bulan. Default menampilkan 27 minggu terakhir dengan sel sekitar 11 dp. Panah 48 dp di kanan judul berpindah ke 6 bulan sebelumnya, jadi data 12 bulan tetap bisa dilihat tanpa membuat kartu tinggi.
Bisa diketuk. Seluruh grid adalah area sentuh. Sel terpilih diberi cincin dan ringkasan berteks muncul di bawahnya. Tombol 48 dp kiri/kanan melompat ke sesi sebelumnya/berikutnya untuk navigasi presisi.
Hari ini diberi cincin biru. Setelah alur prototype selesai, kotak ini terisi.
Sekitar yang tenang. Statistik, PR, dan routine memakai netral baja. Kuningan hanya ikon PR dan angka streak; PR selalu punya ikon piala dan judul "Rekor pribadi".
Routine sebagai playlist. Tile inisial + tombol putar untuk mulai dengan satu ketukan.
